Quick help

How to use: Click Scan → click a row → follow ENTRY / STOP / TARGET → use Notebook to track.

Rule: If STOP hits, exit. Don’t “hope”.

Beginner checklist:

  • Start with Conf 7+ only.
  • Never average down.
  • Size small so a STOP loss is “small”.

Setups (easy)

VWAP Pullback
Price runs up, then pulls back near VWAP (the dotted line) and holds. Entry is when it starts going back up.
Break → Pullback (Retest)
Price breaks above a key level, then comes back to “retest” it. Entry is when the retest holds and it turns up.
Momentum Breakout
Strong uptrend making new highs. Entry is on the break above the recent high (with volume).
Momentum Pullback
Price is trending up, then cools off (small pullback). Entry is when the pullback stops and price turns up again.

Signals

  • Confidence (Conf): Setup quality score. Higher is better, not guaranteed.
  • Move (%): Percent change vs yesterday close.
  • Share Float (SFloat): Shares available to trade. Smaller float can move faster.
  • VWAP: Volume-Weighted Average Price. A line traders watch for support/resistance.

Data sources

  • Polygon: Live market data (price/volume/candles). Powers the scan results.
  • ORTEX: Short interest + borrow data (SI%, borrow cost, availability). Helps confirm squeeze pressure.
